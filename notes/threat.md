# 고급 위협 (APT·킬체인·DLL)

> 자동 생성 — 원본은 `cards/threat.js`. 직접 수정 금지.

## APT 공격 — Advanced Persistent Threat

`시스템 보안`  `지능형 지속 위협` `표적형·장기 잠복` `스피어 피싱 시작` `국가·조직 배후` `킬체인 따라 진행`

**한줄:** 특정 표적을 겨냥해 장기간 은밀히 지속 침투하는 고도화 공격 / 조직적·목적 뚜렷 / 사이버 킬체인 단계를 따름

**정의 (어원=세 단어가 곧 특징)**

**APT = Advanced(고도·지능형) + Persistent(지속·장기 잠복) + Threat(위협)**. 세 단어가 그대로 특징이다. 불특정 다수가 아니라 **특정 대상**을 노려, **오랜 기간 은밀히** 머물며 목적(정보 탈취·감시·파괴)을 이루는 공격.

**특징**

- 단발성 아님 — **표적형**. 대개 **스피어 피싱**(특정인 겨냥 이메일)으로 침투를 시작.
- **장기 잠복**(수개월~수년) 하며 서서히 확산.
- **제로데이** 등 고급 기법 사용.
- 배후가 **국가·조직**인 경우가 많음(예: 스턱스넷).

**어떻게 진행되나**

APT는 대개 **사이버 킬체인** 단계(정찰→무기화→전달→악용→설치→C2→목적달성)를 밟아 진행한다. 그래서 방어도 **킬체인 관점**에서 단계별로 끊는다(킬체인 카드 연결).

**방어**

단일 솔루션으로 못 막는다 → **다층 방어(Defense in Depth)**, **이상 행위 탐지(EDR)**, **위협 인텔리전스**, 로그·이벤트 상시 분석. 핵심은 **킬체인의 어느 단계든 끊는 것**(앞 단계일수록 좋음).

> **시험 한줄정리:** APT = **지능형(Advanced)·지속(Persistent)·위협(Threat)** / 특정 표적을 장기간 은밀히(스피어 피싱 시작) / 킬체인 단계를 밟음 / 방어=다층·이상행위 탐지

_관련 개념: killchain · dll_

## 사이버 킬체인 — Cyber Kill Chain (Lockheed Martin)

`시스템 보안`  `7단계` `정찰→목적달성` `한 단계만 끊어도 차단` `C2` `APT 대응 틀`

**한줄:** 공격을 7단계로 나눈 모델(정찰→무기화→전달→악용→설치→C2→목적달성) / 사슬 중 한 단계만 끊어도 공격 무력화

**정의 (어원으로 기억)**

군사 용어 **킬체인(표적 타격 절차)**을 사이버 공격에 적용한 모델(록히드 마틴). 공격을 **연쇄된 단계**로 보고, **사슬(chain) 중 하나만 끊으면(kill)** 전체 공격이 무력화된다는 **방어 관점**의 틀이다.

**7단계 (순서 암기 — 시험 단골)**

- **1 정찰** — Reconnaissance — 표적 정보 수집.

- **2 무기화** — Weaponization — 익스플로잇+백도어 결합(악성 문서 제작).

- **3 전달** — Delivery — 이메일·USB·웹으로 전달.

- **4 악용** — Exploitation — 취약점 실행.

- **5 설치** — Installation — 백도어 설치(지속성 확보).

- **6 C2** — Command & Control — 외부 서버와 통신·원격 조종.

- **7 목적 달성** — Actions on Objectives — 데이터 탈취·파괴 등.

**방어 관점**

각 단계마다 탐지·차단 수단을 배치하고, **가능한 앞 단계에서 끊을수록** 피해가 작다. APT처럼 단계적으로 진행하는 공격을 **구조적으로 대응**하는 기본 틀. (유사 모델: MITRE ATT&CK)

> **시험 한줄정리:** 사이버 킬체인 = 공격 **7단계**(정찰·무기화·전달·악용·설치·C2·목적달성) / **한 단계만 끊어도 무력화** / APT 대응의 기본 틀

_관련 개념: apt · dll_

## DLL · DLL 공격 — Dynamic Link Library

`시스템 보안`  `동적 링크 라이브러리` `공유 코드 .dll` `DLL 인젝션` `DLL 하이재킹(검색순서)` `정상 프로세스 악용`

**한줄:** 여러 프로그램이 공유하며 실행 시 불러 쓰는 코드 묶음(.dll) / 인젝션·하이재킹으로 정상 프로세스에 악성코드 실행

**정의 (어원으로 기억)**

**DLL = Dynamic Link Library(동적 링크 라이브러리)**. 여러 프로그램이 **공유**하는 함수·코드 묶음을 실행할 때 **동적으로 불러(link)** 쓰는 파일(`.dll`). 컴파일 때 합치는 **정적 링크**와 달리 **실행 시 로드** → 메모리 절약·모듈화. (윈도우 로그인의 옛 GINA도 DLL)

**DLL 인젝션 (Injection)**

다른 **정상 프로세스에 강제로 악성 DLL을 로드**시켜, 그 프로세스의 **권한·신분으로 악성코드를 실행**한다. 정상 프로세스 안에서 도니 **백신·방화벽을 우회**하고 은닉하기 좋다.

**DLL 하이재킹 · 사이드로딩 (검색 순서 악용)**

프로그램이 필요한 DLL을 찾는 **검색 순서(search order)**를 악용한다. 정상 `.exe`가 먼저 뒤지는 위치(예: 실행 폴더)에 **같은 이름의 악성 DLL**을 놓아 두면, **정상 프로그램이 악성 DLL을 로드**한다. 신뢰된 exe가 실행하므로 은닉·지속성에 유리.

**방어**

DLL을 **전체 경로로 명시**해 로드하고 검색 경로를 고정, **SafeDllSearchMode** 활성화, DLL **디지털 서명 검증**, 알려진 DLL 보호(KnownDLLs). 실행 폴더에 낯선 DLL이 없는지 점검.

> **시험 한줄정리:** DLL = 여러 프로그램이 공유하는 **동적 로드 코드 묶음(.dll)** / **인젝션**(정상 프로세스에 악성 DLL 주입) · **하이재킹**(검색 순서 악용해 악성 DLL 로드) / 방어=전체경로·서명검증

_관련 개념: killchain · process · logon_

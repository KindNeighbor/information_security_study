# 네트워크 위협 및 대응 기술

> 자동 생성 — 원본은 `cards/netthreat.js`. 직접 수정 금지.

## 악성 메일 공격 — Malicious Email Attacks

`네트워크 보안`  `APT 초기 침투 1위` `스피어 피싱·웨일링` `매크로·이중 확장자` `샌드박스 검사` `모의훈련이 핵심`

**한줄:** 메일로 악성 첨부·링크를 보내 침투 / 사회공학이라 기술만으론 못 막음 / APT의 대표적 최초 침투 경로 / 대응=샌드박스·첨부 차단·발신자 검증+교육

**유형**

- **피싱(Phishing)** — 불특정 다수에게 미끼 메일을 뿌려 **계정·금융정보**를 낚음
- **스피어 피싱(Spear Phishing)** — **특정 개인·조직을 조사해** 맞춤 제작. 실제 업무 메일처럼 보여 속기 쉽다. **APT의 시작점**
- **웨일링(Whaling)** — **경영진·고위 임원**을 노림(큰 물고기)
- **BEC(업무용 이메일 침해)** — 거래처·임원을 사칭해 **송금·정보 요청**

**침투 수단**

- **악성 첨부파일** — 문서의 **매크로**, **이중 확장자**(`보고서.pdf.exe`)로 위장, 압축파일에 숨기기
- **악성 링크** — 진짜와 비슷한 **피싱 사이트**로 유도해 계정 입력을 유도
- **발신자 위조** — SMTP는 **발신자를 검증하지 않아** 사칭이 쉽다
**[왜 막기 어려운가]** **사회공학**이기 때문이다. 취약점을 뚫는 게 아니라 **사람의 판단을 속인다** — 그래서 **기술적 대책만으로는 한계**가 있고, 이것이 APT의 **최초 침투 경로 1순위**인 이유다.

**대응**

**기술적**
- **샌드박스** — 첨부파일을 **격리된 가상 환경에서 실제로 실행**해 악성 행위를 관찰(알려지지 않은 악성코드에 유효)
- **첨부 확장자 차단**(실행파일 계열), **매크로 기본 비활성화**
- **발신자 검증** — **SPF·DKIM·DMARC**로 위조 메일 차단
- URL 재작성·링크 검사, 스팸·메일 보안 솔루션
**관리적** — **모의 훈련과 보안 인식 교육**이 사실상 가장 효과적이다. **신고 창구**를 만들어 의심 메일을 쉽게 알리게 한다.

> **시험 한줄정리:** 악성메일 = **피싱 / 스피어 피싱(표적·APT 시작점) / 웨일링(임원) / BEC(사칭 송금)** / 수단=**매크로·이중 확장자·악성 링크·발신자 위조** / **사회공학이라 기술만으론 한계** → **샌드박스·첨부 차단·SPF/DKIM/DMARC + 모의훈련·교육**

_관련 개념: ransomware · smtp · apt_

## 랜섬웨어 · APT형 표적 공격 — Ransomware · APT-style Attack

`네트워크 보안`  `파일 암호화 후 몸값` `APT형 표적화` `이중 갈취` `백업까지 파괴` `3-2-1 백업`

**한줄:** 파일을 암호화하고 복호화 대가를 요구 / 무차별 유포에서 APT식 표적 공격으로 진화 / 백업까지 파괴하고 데이터를 먼저 유출해 협박(이중 갈취)

**정의 · 진화**

**랜섬웨어** = **Ransom(몸값) + Software**. 파일을 암호화해 못 쓰게 만들고 **복호화 키의 대가로 금전**을 요구한다.**[무엇이 달라졌나]** 예전에는 **불특정 다수에게 뿌리는** 방식이었지만, 지금은 **APT처럼 특정 조직을 노려 준비한 뒤 한 방에** 터뜨린다. **RaaS(서비스형 랜섬웨어)**로 기술이 없어도 공격을 구매할 수 있게 되면서 더 흔해졌다.

**APT형 랜섬웨어의 진행 (킬체인과 동일)**

- **1 침투** — **스피어 피싱 메일**·노출된 **RDP**·VPN 취약점으로 최초 진입

- **2 권한 상승·확산** — 계정 탈취 후 **내부를 측면 이동**하며 범위를 넓힘

- **3 데이터 유출** — 암호화 **전에 먼저 자료를 빼돌린다**

- **4 백업 파괴** — **백업·섀도 복사본을 먼저 삭제**해 복구 수단을 없앰

- **5 암호화·협박** — 일제히 암호화 후 몸값 요구

**[이중 갈취(Double Extortion)]** “돈을 안 내면 **훔친 자료를 공개하겠다**”. **백업이 있어서 복구할 수 있어도** 유출 협박 때문에 굴복시키려는 수법이다.

**대응 — 백업이 최선**

- **3-2-1 백업 규칙** — 사본 **3**개, 서로 다른 매체 **2**개, **오프사이트(외부) 1**개
- **오프라인·불변(WORM) 백업** — 랜섬웨어가 **연결된 백업까지 지우므로** 네트워크에서 분리된 사본이 반드시 필요하다. **복구 훈련**도 정기적으로
- **초기 침투 차단** — 메일 보안·교육, **RDP 인터넷 노출 금지**·MFA, 취약점 패치
- **확산 차단** — **망분리·네트워크 분할**, 최소 권한, EDR로 이상 행위 탐지
- **몸값 지불은 권장되지 않는다** — 복구를 보장하지 않고 재범을 부추긴다

> **시험 한줄정리:** 랜섬웨어=암호화 후 몸값 / 요즘은 **APT형 표적 공격**(침투→확산→**유출**→**백업 파괴**→암호화) / **이중 갈취**=유출 자료 공개 협박 → 백업만으론 부족 / 대응=**3-2-1 백업·오프라인 사본**·RDP 차단·메일 보안·**망분리로 확산 차단**

_관련 개념: mailattack · netsep · apt_

## 망분리 (인터넷 접속 차단) — Network Separation

`네트워크 보안`  `업무망 vs 인터넷망` `물리적 분리` `논리적 분리 SBC·CBC` `악성코드 유입·자료 유출 차단` `비용 vs 보안`

**한줄:** 업무망과 인터넷망을 분리해 악성코드 유입과 자료 유출을 차단 / 물리적 분리(PC 2대·보안 최고·비용↑) vs 논리적 분리(가상화·SBC/CBC·비용↓)

**왜 하는가**

대부분의 침해는 **인터넷을 통해 들어오고 인터넷을 통해 나간다**. 그래서 아예 **업무망과 인터넷망을 끊어 놓으면**:
- **악성코드 유입 차단** — 메일·웹으로 들어오는 경로 자체를 없앰
- **내부 자료 유출 차단** — 유출하려 해도 **내보낼 통로가 없다**
- 랜섬웨어의 **내부 확산**도 제한된다
공공기관·금융권 등에서는 **법·규정으로 의무화**되어 있다.

**물리적 망분리 vs 논리적 망분리**

- **물리적 망분리**: 업무용·인터넷용 **PC와 네트워크를 물리적으로 따로** 둔다(2대 또는 망전환 장치).
➕ **보안성이 가장 높다**
➖ **장비·공간·비용 부담**이 크고 사용자가 불편하다

- **논리적 망분리**: **가상화 기술**로 한 PC 안에서 두 영역을 나눈다.
➕ **비용이 낮고** 도입·운영이 유연
➖ **가상화가 뚫리면 분리도 무너져** 물리적 분리보다 보안이 약하다

**논리적 망분리 — SBC vs CBC (출제)**

- **SBC (Server Based Computing)**: **서버에 가상 데스크톱을 두고** 사용자가 원격으로 접속해 쓴다(VDI).
➕ **중앙에서 통제·관리**가 쉽고 단말에 자료가 남지 않는다
➖ **서버 투자와 네트워크 부하**가 크다

- **CBC (Client Based Computing)**: **PC 내부에 가상 영역**을 만들어 업무/인터넷을 분리한다.
➕ **서버 부담이 적고** 비용이 낮다
➖ **PC 성능**이 필요하고 **단말에서 분리가 깨질** 위험이 상대적으로 크다

**구분 요령**: **S**erver=서버에 둔다, **C**lient=클라이언트(PC)에 둔다.

> **시험 한줄정리:** 망분리=업무망↔인터넷망 차단(**악성코드 유입·자료 유출·확산** 방지) / **물리적**(PC 2대·**보안 최고**·비용↑) vs **논리적**(가상화·비용↓·상대적 취약) / 논리적은 **SBC(서버에 가상 데스크톱·중앙통제)** vs **CBC(PC 안에 가상영역·서버부담↓)**

_관련 개념: netlink · ransomware · firewall_

## 망연계 · 자료연계 — Network Interlock / Data Transfer

`네트워크 보안`  `분리했으니 연결이 필요` `스토리지 연계` `인피니밴드` `소켓 연계` `일방향·악성코드 검사`

**한줄:** 망을 분리하면 자료를 못 주고받으므로, 통제된 방법으로만 전달하는 장치 / 방식=스토리지 연계·인피니밴드·소켓 연계 / 요건=일방향·악성코드 검사·승인·로그

**왜 필요한가 — 망분리의 필연적 짝**

망을 분리하면 보안은 좋아지지만 **업무에 필요한 자료를 주고받을 수 없다**. 그렇다고 **USB로 옮기면** 통제가 안 되고 **악성코드 유입·자료 유출**이 그대로 일어난다.**[그래서]** **정해진 통로로, 검사와 승인을 거쳐서만** 자료가 오가도록 하는 시스템이 **망연계(자료연계)**다. **망분리와 망연계는 한 세트**로 기억한다.

**연계 방식**

- **스토리지 연계** — 두 망 사이에 **공유 저장장치**를 두고, **양쪽이 동시에 붙지 못하게** 번갈아 접근시킨다. 한쪽이 쓰고 연결이 끊긴 뒤 다른 쪽이 읽는 식이라 **물리적 단절이 유지**된다
- **인피니밴드(InfiniBand) 연계** — **고속·저지연 인터커넥트** 기술을 이용. **대용량 자료를 빠르게** 옮겨야 할 때 유리하다
- **소켓(네트워크) 연계** — 응용 계층에서 **데이터만 전달**하고 일반 프로토콜은 차단. 구성이 유연하다
- **DB 연계** — 지정된 테이블·항목만 주고받는다

**보안 요건**

- **일방향 전송** — 필요하면 **한 방향으로만** 흐르게 해 역방향 유출을 원천 차단
- **악성코드 검사** — 넘어가는 파일을 백신·**샌드박스**로 검사
- **승인·결재 절차** — 반출 자료는 **담당자 승인**을 거치게
- **로그·감사** — 누가 언제 무엇을 옮겼는지 기록해 **추적 가능**하게
- 연계 구간 자체가 **두 망을 잇는 유일한 통로**이므로, 이 시스템이 뚫리면 망분리가 무의미해진다 → **최소 기능·강화된 통제**가 필수

> **시험 한줄정리:** 망연계=분리된 망 사이에 **통제된 자료 전달**(망분리와 한 세트) / 방식 **스토리지 연계(번갈아 접근·물리 단절 유지)**·**인피니밴드(고속·대용량)**·**소켓 연계(데이터만)**·DB 연계 / 요건=**일방향·악성코드 검사·승인·로그**

_관련 개념: netsep · ransomware · firewall_

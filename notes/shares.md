# 공유·프로토콜 (SMB 계열)

> 자동 생성 — 원본은 `cards/shares.js`. 직접 수정 금지.

## NetBIOS — Network Basic Input/Output System

`시스템 보안`  `137` `138` `139` `널세션 표적` `레거시`

**한줄:** LAN 내 이름 기반 통신 / 포트 137·138·139(+445) / 널세션 정보유출 / 안 쓰면 차단

**정의**

같은 근거리망(LAN) 안에서 컴퓨터를 **IP가 아닌 이름**(예: `DESKTOP-ABC123`)으로 찾고 통신하게 해주는 옛 윈도우 기술. 탐색기 '네트워크'에 뜨는 PC 이름들이 이거.

**포트 (세트로 암기)**

- `137` — 이름 서비스(Name Service).
- `138` — 데이터그램(Datagram).
- `139` — 세션 서비스(Session Service).
여기에 `445`(SMB over TCP)까지 묶어서 기억한다. 요즘은 139 대신 **445**로 넘어갔다.

**취약점**

보안 개념이 거의 없던 시절 기술. 외부 노출 시 **널 세션(Null Session)**으로 인증 없이 접속해 사용자 목록·공유·정책 정보를 긁어감(정찰 단계 단골). 도구: `nbtstat`, nbtscan, enum4linux.

**방어**

쓸 거 아니면 막아라. 외부로 향하는 `137~139`·`445` 차단, 안 쓰면 NetBIOS over TCP/IP 비활성화. '안 쓰는데 켜진 서비스'를 줄이는 **공격 표면 최소화(하드닝)**의 교과서적 예시.

**왜 아직 쓰이나**

기술이 좋아서가 아니라 **레거시 호환성** 때문. 공장·병원·관공서의 구형 시스템이 아직 의존. 추세는 확실히 퇴출 → 시험에선 대개 '차단·비활성화 대상'으로 출제.

> **시험 한줄정리:** NetBIOS = LAN 이름 통신 / 137·138·139(+445) / 널세션으로 정보 유출 / **안 쓰면 꺼야 할 1순위**

_관련 개념: smb · ipc_

## SMB / CIFS — Server Message Block

`시스템 보안`  `445` `CIFS=SMBv1` `EternalBlue` `워너크라이`

**한줄:** 윈도우 파일공유 프로토콜 / CIFS=SMBv1(취약) / SMBv2·v3는 암호화·무결성 / 포트 445

**정의**

윈도우 파일·프린터 공유 프로토콜. **CIFS(Common Internet File System)는 SMB의 옛 이름 = SMBv1 계열.** IPC$·널세션도 전부 이 위에서 돌아감. 포트 `445`(+ 139).

**NetBIOS와의 관계 — '업그레이드' 아님 (함정 주의)**

옛날에는 **SMB가 NetBIOS 위에 얹혀서** 돌아, NetBIOS 포트 `137`·`138`·`139`를 세트로 함께 썼다. 이후 SMB가 `445`에서 **직접(direct hosting)** 동작하게 되면서 NetBIOS 의존을 끊었다. 하지만 이건 버전 업그레이드가 아니라, 둘은 **역할이 다른 별개의 두 계층**이라는 게 핵심이다.
- **NetBIOS · 하부**: 같은 랜(LAN) 안에서 **컴퓨터 이름을 찾고 세션을 연결**해 주는 도우미 역할.

- **SMB · 응용**: 그 연결 위에서 **실제 파일·프린터를 공유**하는 역할.

**[시험 함정]** 'SMB는 NetBIOS의 개선판인가?' → **❌ 아니다.** 위에 얹혀 있다가 `445`로 독립한 **계층 관계**일 뿐, 버전 업그레이드가 아니다.

**SMBv1(CIFS)의 취약점 — 워너크라이**

SMBv1의 **EternalBlue** 취약점(NSA 유출)으로 **인증 없이 원격 코드 실행** 가능. 2017 **워너크라이** 랜섬웨어가 이걸 써서 같은 망으로 자가 전파(웜)했던 대형 사고. 시험엔 EternalBlue·WannaCry·SMBv1이 세트로 출제.

**방어**

**SMBv1(CIFS)은 끄고 SMBv2/v3를 써라.** 특히 SMBv3는 전송 암호화·무결성 검증이 들어가 보안이 크게 개선됨. '더 새 기술이라 안전'이 아니라 **버전으로 판단**하는 게 핵심.

**버전 진화 관점**

SMB는 버전이 올라가며 옛날엔 없던 **인증·무결성·암호화**를 채워 왔다.
- **SMBv1 (CIFS)** — 가장 오래된 버전. 암호화·무결성이 **없다** → **EternalBlue** 취약점, 워너크라이의 무대.

- **SMBv2** — 프로토콜을 정리하고 효율을 개선.

- **SMBv3** — **전송 암호화·무결성 검증**이 들어가 보안이 크게 강화.

**[주의]** **NetBIOS→SMB**는 이런 '버전 업'이 아니라 계층 의존이 끊긴 것 — 위 'NetBIOS와의 관계' 블록 참고.

> **시험 한줄정리:** CIFS = SMBv1(취약, 비활성화 대상) · EternalBlue/워너크라이 / **SMBv2·v3 = 암호화·무결성 적용판** / 포트 445

_관련 개념: netbios · ipc_

## IPC$ · 널 세션 — Inter-Process Communication Share

`시스템 보안`  `숨김 공유` `Null Session` `RestrictAnonymous`

**한줄:** 윈도우 기본 숨김 관리 공유 / 널세션이 빈 자격증명으로 접속 / RestrictAnonymous로 차단

**정의**

윈도우가 자동 생성하는 **숨겨진 관리용 공유**(끝의 `$`=숨김). 파일 공유가 아니라 컴퓨터 간 **프로세스 통신**(원격 서비스 제어·인증·이름 조회)을 위한 통로.

**널 세션(Null Session)**

옛 윈도우는 IPC$ 접속 시 **아이디·비밀번호를 비워도 허용**했음. 이 빈 연결을 발판으로 사용자 계정·공유·정책 정보를 열람(enumeration).

```
net use \\대상IP\IPC$ "" /user:""
```

**공격 사슬**

- **① 포트 개방** — SMB 포트(`139`·`445`)가 열려 있음.

- **② IPC$ 접속** — 숨김 공유 `IPC$`에 연결.

- **③ 널세션** — 빈 자격증명으로 **널세션 성립**.

- **④ 정보 수집** — 계정·공유·정책 등 시스템 정보 열람.

**[시험]** '널세션이 이용하는 기본 공유는?' → **IPC$** (양방향으로 출제).

**방어**

레지스트리 `RestrictAnonymous`(또는 RestrictAnonymousSAM) 값을 올려 익명 접속 제한. 근본적으론 `139`·`445`를 외부에 노출하지 않기. IPC$ 자체는 정상 기능 — 문제는 '인증 없이 통하던 것'.

> **시험 한줄정리:** IPC$ = 윈도우 기본 숨김 관리 공유 / **널세션**이 빈 자격증명으로 접속 / **RestrictAnonymous**로 차단

_관련 개념: smb · netbios · adminshares_

## 관리 목적 기본 공유 — Administrative / Hidden Shares

`시스템 보안`  `$=숨김공유` `C$` `ADMIN$` `IPC$` `PsExec 측면이동` `net share`

**한줄:** 윈도우가 자동 생성하는 숨김 관리 공유(C$·ADMIN$·IPC$) / 관리자 권한 필요 / 탈취 계정으로 측면이동에 악용

**정의**

윈도우 설치 시 **자동 생성**되는 숨겨진 관리용 공유. 이름 끝의 `$`=탐색기에 안 보이는 **숨김 공유**. 원격 관리 편의를 위해 존재. 현재 목록은 `net share`로 확인.

**종류 (세트로 암기)**

- `C$` — 각 드라이브 루트(C$·D$…)에 대한 관리 공유.
- `ADMIN$` — `C:\Windows`(%SystemRoot%) 폴더. 원격 관리용.
- `IPC$` — 프로세스 간 통신 통로(옛 **널세션**의 발판).
- `PRINT$` — 프린터 드라이버 공유.
**[출제 단골]** 앞의 셋 **C$·ADMIN$·IPC$**가 시험에 자주 나온다.

**악용 — 측면 이동(lateral movement)**

공유 자체는 **관리자만 접근**하는 정상 기능이다. 문제는 **관리자 자격증명을 탈취한 뒤**부터다.
- **① 복사** — **PsExec**류가 `ADMIN$`에 서비스 바이너리를 복사.

- **② 원격 실행** — `IPC$`·명명된 파이프로 그 서비스를 원격 실행.

- **③ 전파** — 같은 방식으로 **옆 PC로 번짐**(측면 이동).

참고로 `IPC$`는 옛날 **널세션**으로 인증 전에 정보까지 흘렸다.

**방어**

근본은 **관리자 자격증명 보호**: **LAPS(Local Administrator Password Solution)**로 로컬관리자 암호를 PC마다 다르게(패스더해시 대비). 망 분리·`445` 외부 차단. 필요 시 레지스트리 `AutoShareWks`/`AutoShareServer`=0으로 자동 공유 끄기(단 원격 관리도구 영향). 널세션은 `RestrictAnonymous`.

> **시험 한줄정리:** 기본(관리) 공유 = 자동 생성 숨김 공유 **C$·ADMIN$·IPC$** / 관리자만 접근 / **탈취 계정으로 PsExec 측면이동**에 악용 / IPC$는 널세션

_관련 개념: ipc · smb_

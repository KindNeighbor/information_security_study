### 네트워크
- **콜리전 vs 브로드캐스트 도메인** — 4회차. 콜리전=스위치 정답. 브로드캐스트를 "L4"로 답함 → 정답 **L3 라우터·VLAN**
- **허브 vs 스위치** — 방향은 맞음. 남은 연결: 허브는 1계층이라 주소 개념 없이 모든 포트로 복사 / 스위치는 MAC 테이블 → **그래서 스니핑하려면 ARP 스푸핑·MAC 플러딩이 필요**
- **캡슐화 · PDU · 계층별 헤더** — 방향은 스스로 재구성했으나 용어가 안 붙음. 데이터→(TCP)세그먼트→(IP)패킷→(MAC)프레임→신호
- **목적지 MAC 판단 규칙** — "같은 랜인데 공유기 MAC 아니야?" 오답. 규칙: **같은 네트워크면 ARP로 상대 MAC, 다른 네트워크면 게이트웨이 MAC**
- **NAT · PAT** — 공유기 안쪽 사설 IP는 서로 다름(.2/.3/.4). 바깥에서 하나로 보이는 게 NAT, 포트로 구분하는 게 PAT
- **SNMP 포트 161/162** — 3회차까지 "102, 103?". 161=매니저 조회, 162=에이전트 트랩. 고리: 큰 번호가 능동 알림
- **사설 IP 172 범위** — 172.16 ~ 172.31 (`/12`). 고리: **16에서 시작해 16개**
- **UDP 헤더 4필드** — 2회 백지. 출발지·목적지 포트 + 길이 + 체크섬(8바이트) = TCP에서 신뢰성 필드를 뺀 나머지
- **TCP 4-way 종료 이유** — 전이중이라 방향별로 닫아야 하고 ACK와 FIN 사이에 시간이 필요해 못 합침
- **SYN Flooding** — 원리는 안정적. 남은 것: 상태명 **SYN_RECEIVED**(SYN_ACCEPT로 씀), 고갈 대상 **백로그 큐**
- **Ping of Death vs Teardrop** — 하루 뒤 재확인 실패. **PoD=크기**(65,535 초과) / **Teardrop=오프셋** 조작. tear=찢다
- **Boink** — 오프셋을 일정하게 어긋나게 (Bonk는 전부 동일)
- **RIP 상한** — 풀네임은 해결. 남은 것은 **최대 15홉(16=도달 불가)** 숫자
- **프로토콜 번호** 1=ICMP, 6=TCP, 17=UDP / **헤더 크기** IP·TCP 20바이트, UDP 8바이트 / **오프셋 단위** 8바이트
- **HTTP 3대 특징** — 요청-응답 / 비연결성(선을 끊는다) / 무상태(기억을 못 한다)
- **HTTP/1.0 vs 1.1** — 1.1 = 지속 연결(Keep-Alive) + **Host 헤더 필수**
- **enable password vs secret** — password=평문 노출, secret=해시·**우선 적용**

### 시스템 · 윈도우
- **utmp / wtmp / btmp** — utmp를 2회 "로그인 기록"으로 오해. 정답은 **현재 접속 중**(who/w). wtmp=이력(last), btmp=실패(lastb)
- **DAC vs MAC** — 번역은 정답. 남은 것: **누가 정하는가** — DAC=소유자 재량, MAC=시스템·관리자가 보안등급 라벨로 강제
- **GINA vs Credential Provider** — 4회차. Vista 교체는 정답. 남은 것: 둘 다 **자격증명 수집 UI**일 뿐이고 인증은 LSA가 함 / 통짜 `msgina.dll` vs 모듈식 복수 등록
- **DRDoS** — 원리는 정확. 용어만 누락: **반사(reflection)·증폭(amplification)**
- **Pass-the-Hash** — 원리는 정답. 용어 누락: NTLM 챌린지-리스폰스 / LSASS 메모리 탈취 / 횡적 이동
- **HTTP GET Flooding · Cache Control** — 3-way 완성이 필요해 IP 위조 불가 → 실제 좀비 PC 필요

### 신규 3파일 (netattack · firewall · vpnetc) — 09-06 1회차, 대부분 백지
- **포트 스캔 판정** — SYN+ACK=열림 / RST=닫힘 / 무응답=필터링. SYN 스캔은 RST로 끊어 **로그를 안 남김**(스텔스)
- **방화벽 유형** — 패킷필터링(3·4계층) / 회선 게이트웨이(5) / 애플리케이션 게이트웨이(7·프록시) / 상태기반 검사(세션 문맥 기억·주류). 기본 정책 **Deny All 후 필요한 것만**
- **방화벽 구축 형태** — 스크리닝 라우터 → 듀얼 홈드 → 스크린드 호스트 → **스크린드 서브넷**(라우터 2개 + DMZ, 가장 안전). 베스천 호스트는 형태가 아니라 강화된 최전방 호스트
- **IDS vs IPS** — 위치가 다름. IDS=**미러링(옆에서)**·탐지만 / IPS=**인라인(경로 위)**·실시간 차단. 대가는 IPS 오탐 시 정상 트래픽까지 차단
- **HIDS vs NIDS** — 갈림길은 **암호화를 보느냐**. HIDS는 호스트 안이라 복호화 후를 봄(부하) / NIDS는 패킷이라 암호화되면 못 봄(광범위)
- **지식 기반 vs 행위 기반** — 시그니처(오탐↓·제로데이 X) vs 프로파일(제로데이 O·오탐↑). 백신 시그니처 vs 휴리스틱과 같은 구조
- **AH vs ESP** — 이름이 정직. AH=Authentication Header → **인증만**, 암호화 없음, 프로토콜 **51** / ESP → **암호화+인증**, **50**
- **무선랜** — WEP(RC4·IV가 짧아 반복) → WPA(TKIP) → WPA2(AES-CCMP·802.11i) → WPA3(SAE). Personal=PSK / Enterprise=802.1X+RADIUS
- **스위치 스니핑** — "MAC을 알아야"가 아니라 **스위치가 내 포트로 안 보내주는 것**이 문제. ARP 스푸핑(게이트웨이 사칭) 또는 MAC 플러딩(테이블을 넘쳐 허브처럼 만들기)

## 2. 선행 지식 공백 — 반복된 진짜 원인

개념이 계속 안 붙을 때는 암기 부족이 아니라 **밑에 빠진 단어**가 원인이었다. 지금까지 8회 반복된 패턴.

- **IP 단편 재조립 · 오프셋** — 뜻을 모른 채 "Teardrop은 오프셋을 겹치게"를 외우고 있었음
- **프로세스에도 UID가 붙어 있다** — 이걸 모른 채 SetUID를 외우려 해서 계속 실패
- **삭제 권한은 파일이 아니라 디렉터리의 쓰기 권한에서 나온다** — 스티키 비트(`/tmp` 1777)의 전제
- **각 계층의 "주소"가 무엇인가** — 1=주소 없음 / 2=MAC / 3=IP / 4=포트 번호
- **MAC 주소에는 위치 정보가 없다** — 스위치가 "출발지 MAC = 들어온 포트"를 기록해 표를 스스로 만듦(MAC 학습). 표가 가득 차면 허브처럼 동작 = MAC 플러딩
- **브로드캐스트 MAC(FF:FF:FF:FF:FF:FF)** — 특정 장비가 아니라 "이 랜 전원"이라는 약속. 표에 올라올 수 없으니 스위치는 전부로 복사, 라우터는 MAC 헤더를 벗고 IP를 보므로 안 넘김. ARP 요청이 이것이라 랜을 못 넘음
- **DLL이 무엇인가** — 정적 링크 vs 동적 링크. DLL 인젝션 / 하이재킹 / GINA 트로이목마로 이어짐
- **취약점 공격 vs 악성코드 설치** — 취약한 코드는 원래 피해자 OS에 있고 공격자는 패킷만 보냄. 그래서 대응이 백신이 아니라 **패치**. DDoS의 악성코드는 피해자가 아니라 **좀비 PC**에 심는 것
- **라우팅은 경로 결정이지 이름 해석이 아니다** — "동적 라우팅=도메인?"이라 답했던 오해

## 3. 해결됨 (하루 이상 간격 두고 재확인 통과)

- **스머프 vs Fraggle** — ICMP vs UDP. 3회 놓친 뒤 **"스머프는 핑"** 고리 하나로 해결
- **HULK** — URL 파라미터를 매번 랜덤화해 캐시 무력화
- **TCP 플래그 6종** — URG·ACK·PSH·RST·SYN·FIN. 연결 담당(SYN·FIN·RST) / 데이터 담당(ACK·PSH·URG)
- **특수 권한** — SetUID 4000(소유자 `s`) / SetGID 2000(그룹 `s`) / 스티키 1000(기타 `t`)
- **SetUID 원리** — 검사를 건너뛰는 게 아니라 **검사받는 신분이 파일 소유자로 바뀜**
- **umask** — 기본 권한(파일 666·디렉터리 777)에서 뺌. 022 → 644
- **심볼릭 vs 하드 링크** — 하드는 같은 inode라 원본을 지워도 데이터가 살아있음. 심링크는 깨짐
- **인증 vs 인가** — 401/403, LSA/SRM 양쪽 모두 정답. 개념 전이 확인
- **Kerberos 티켓 발급처** — AS가 TGT → 그 TGT로 TGS에서 서비스 티켓
- **winlogon vs lsass** — 진행 총괄(사회자) vs 검증(심사관)
- **쿠키 3옵션** — Secure→도청 / HttpOnly→XSS / SameSite→CSRF
- **TRACE · XST** — 응답 본문으로 쿠키가 새어 **HttpOnly를 우회**
- **비연결성 vs 무상태** — 선을 끊는다 vs 기억을 못 한다
- **허브1 · 스위치2 · 라우터3 계층** (L4 스위치가 4계층)
- **약어** SAS · SACL · LSA · GINA · NTLM · TGT · RIP · SMTP 25 · SYN_RECEIVED · 위장 프로세스(System32 경로)

## 4. 통했던 설명 방식

- **원리형과 암기형은 대응이 다르다.** 원리가 있는 개념은 비유·메커니즘 한 번에 붙는다. 원리 없이 짝만 있는 것(Fraggle, Bonk/Boink, 포트 번호, 플래그 나열)은 **억지 기억 고리**를 걸고 **다음 날 다시** 꺼내야 한다
- **설명 직후 재확인은 원리형에만 유효하다.** 암기형은 단기기억 복사라 의미가 없다 — 하루 이상 두고 물을 것
- **읽기는 인출이 아니다.** 카드에 다 있는데도 안 외워졌던 이유
- **풀네임을 이해하면 약어가 붙는다.** 대부분의 이름은 정직하다 — OSPF=Open Shortest Path First, SAM=Security Account Manager, AH=Authentication Header
- **네트워크 장비는 동작을 외우지 말고 하나에서 파생시킨다** — 차이는 **"무엇까지 읽을 수 있느냐"** 하나. 허브=못 읽음 / 스위치=MAC / 라우터=IP. 그리고 **"읽을 게 없으면 뿌릴 수밖에 없다."** 콜리전 도메인·허브 스니핑·MAC 테이블·MAC 플러딩·ARP 스푸핑·브로드캐스트 도메인 경계가 전부 여기서 나옴
- 참고: 네트워크 뼈대 정리 아티팩트를 따로 만들어 뒀음(막히면 처음부터 재설명하지 말고 그 위에 얹기)
